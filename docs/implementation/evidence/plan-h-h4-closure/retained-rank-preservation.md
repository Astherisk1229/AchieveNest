# Retained Rank Preservation

## Invariant
When an evaluation results in `Retained`, the faculty/personnel member's current rank/title must remain unchanged. No automatic promotion decision is triggered, no rank advancement is applied, and no demotion occurs.

## Validation Status
- **Result**: `VERIFIED`
- **Evaluation Result**: `Retained` (persisted separately from promotion decision).
- **Promotion Decision**: `null` (not applicable / not auto-triggered).
- **Candidate Current Rank**: Retained at pre-evaluation rank.
- **Rank Advancement**: None generated.
- **Demotion**: None.
