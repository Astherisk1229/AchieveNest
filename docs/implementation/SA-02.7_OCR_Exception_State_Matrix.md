# SA-02.7 — OCR Exception State Matrix

## 1. Document Purpose
This document establishes the standardized internal and user-facing state machine for OCR text extraction, entity parsing, and exception management in AchieveNest.

---

## 2. Master Extraction State Definitions

| State Code | State Label | Trigger / Condition | Field Presentation | Editable by Student? | Final Submission Impact | Verification Impact |
|---|---|---|---|---|---|---|
| **`NOT_STARTED`** | Not Scanned | No evidence file has been uploaded yet, or document scan has not been initiated. | Fields remain empty or retain initial values. | **YES** | Non-blocking if fields filled manually; blocked if required fields empty. | None (Record is `draft`). |
| **`PROCESSING`** | Scanning & Extracting | Evidence binary is being parsed by `OcrScanController` (magic bytes, text streams, OCR raster). | Loading spinner / progress indicator in upload zone. Fields remain active. | **YES** | Non-blocking. | None. |
| **`EXTRACTED`** | Successfully Extracted | Document text parsed cleanly; field extracted with high confidence; single deterministic value found. | Value populated into input field as suggestion badge/chip. | **YES** | Non-blocking. | None (Suggestion only; record remains unverified). |
| **`PARTIAL`** | Partially Extracted | Value is syntactically incomplete (e.g., date missing year, role missing scope, truncated title). | Value pre-fills partial fragment; UI prompts: *"Please complete missing details"*. | **YES** | Non-blocking for draft; blocked at final submission if incomplete. | None. |
| **`NO_VALUE`** | No Text Detected | Engine finds no text or cue corresponding to the specific field in the document. | Field remains blank. | **YES** | Non-blocking for draft; blocked at final submission if field is required. | None. |
| **`NO_MATCH`** | Dropdown No Match | Extracted text does not match any SA-02.3 canonical option or authorized alias. | Dropdown remains unselected (`""`). Student selects canonical option manually. | **YES** | Non-blocking for draft; blocked at final submission if field is required. | None. |
| **`AMBIGUOUS`** | Ambiguous Multiple Values | Multiple plausible dates, scopes, or conflicting entities detected in evidence. | UI flags ambiguity chip with detected candidate options; no auto-selection. | **YES** | Non-blocking for draft; blocked at final submission until student confirms selection. | None. |
| **`INVALID_VALUE`** | Invalid Syntactic Value | Extracted text violates format rules (e.g., impossible calendar date Feb 31, negative hours). | Field rejected from pre-fill; UI warning displayed. | **YES** | Non-blocking for draft; blocked at final submission if required. | None. |
| **`MANUALLY_OVERRIDDEN`** | Student Overridden | Student modified or replaced an OCR pre-filled suggestion with manual input. | Student's value is authoritative; OCR provenance preserved in metadata trace. | **YES** | Non-blocking. | None. |
| **`MANUAL_PRESERVED`** | Existing Value Kept | Student entered a manual value before OCR completed; OCR did not overwrite (`DO_NOT_OVERWRITE_MANUAL_VALUE`). | Student's input remains in field; OCR result offered as advisory suggestion chip. | **YES** | Non-blocking. | None. |
| **`FAILED`** | OCR Processing Failed | File corrupt, unreadable encoding, OCR engine timeout, or zero text layer in scanned PDF. | Non-blocking error banner: *"OCR could not extract text. Please enter details manually."* File remains attached. | **YES** | **NON-BLOCKING**. Student can complete entire form manually. | None. |


---

## 4. Key Invariant Guarantees
1. Every state allows immediate, unblocked manual editing by the student.
2. `FAILED` or `NO_VALUE` states **never** invalidate the attached evidence file or prevent submission if all required fields are manually filled.
3. No transition into a verified evaluation state exists anywhere in the extraction state machine.
