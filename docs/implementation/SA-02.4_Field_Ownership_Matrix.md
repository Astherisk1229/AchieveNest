## 1. Document Purpose & Phase Scope

This document establishes the definitive **Field Ownership Matrix** across the student submission, verification, and award evaluation lifecycle.

### Non-Negotiable Invariants:
1. **Verification Status Is System-Managed:** `verification_status`, `verified_by`, `verified_at` are strictly controlled by the Evaluator/OSAD verification engine.
2. **Scoring Is Read-Only / System-Managed:** Students cannot set or manipulate `score`, `points`, `rubric`, or `award_id`.
3. **Identity Session Binding:** `student_profile_id` is automatically derived from the authenticated JWT session.
4. **Internal IDs Are Immutable:** Record UUIDs, evidence hashes, and audit event logs are generated and locked by the database.

## 3. Summary & Verification

- **Student-Editable Fields:** 19 fields (Title, Categories, Dates, Description, Evidence, Structured Metadata Dropdowns).
- **Read-Only Visible Fields:** 5 fields (Evaluator Feedback, Student Name/ID, Category/Subcategory Labels).
- **System-Derived Fields:** 4 fields (Session Owner ID, Award Points, Potential Flag, File Hash).
- **System-Managed Workflow Fields:** 3 fields (`status`, `verified_by`, `verified_at`).
- **Internal-Only Fields:** 1 field (Database UUID).
- **Security Check:** Mass-assignment attempts to inject `status`, `verified_by`, `score`, or `award_id` are strictly rejected by `PortfolioStructuredMetadataValidator::FORBIDDEN_METADATA_KEYS` and controller parameter binding.
