# Rank History Audit & Persistence Validation Evidence

When an approved promotion is finalized:
- `personnel_id`: Verified persona ID.
- `old_rank`: Canonical prior rank code.
- `new_rank`: Canonical newly applied rank code.
- `transition_type`: `normal_sequential` or `verified_phd_exception`.
- `effective_date`: Persisted ISO date timestamp.
- **Result**: Full historical lineage maintained.
