# Finalization & Promotion Event Audit (Plan H)

## Finalization Lifecycle
1. **Readiness Check (H0)**: Evaluates preconditions (scoring complete, scale valid, evidence intact).
2. **Result Determination (F5/H1)**: Records `Passed` or `Retained`.
3. **Summary Print Generation (H2)**: Assembles multi-page rating sheet export.
4. **Promotion Decision (H3)**: HR records `Approved` or `Not Approved` and updates rank.
5. **Final Lock (H4)**: Seals evaluation as `completed` with immutable timestamp.
