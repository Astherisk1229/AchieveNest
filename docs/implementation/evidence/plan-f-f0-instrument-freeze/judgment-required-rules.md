# Plan F Phase F0 Evidence: Evaluator Judgment Required Rules

## Invariant Summary

For categories where the official instrument provides only an accepted maximum ceiling without an explicit lower-level formula:
1. The official maximum cap is preserved.
2. The category is flagged with `evaluator_judgment_required = true`.
3. The system does NOT invent arbitrary lower-level scoring formulas or fake points.
4. Final accepted score determination is deferred to authorized evaluators in Plan G.

2. **Administrators Scale B.6 — Creative Work**: Max `20.0` points.
