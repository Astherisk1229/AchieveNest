# Audit Persistence Schema Evidence

### Record Fields
- `id` (string, UUID or canonical audit ID)
- `audit_event_key` (string, canonical event key)
- `audit_display_label` (string, human-readable label)
- `actor_user_id` (string, authenticated user ID)
- `actor_role` (string, `Personnel`, `Dean`, `HR`, `System`)
- `actor_context` (JSON object, e.g. college code, assignment scope)
- `subject_personnel_id` (string, affected candidate profile ID)
- `evaluation_id` (string, nullable)
- `portfolio_version_id` (string, nullable)
- `portfolio_version_number` (integer, default 1)
- `entity_type` (string, e.g. `personnel_evaluation`, `portfolio_entry`)
- `entity_id` (string, target entity ID)
- `before_state` (JSON / string, state prior to mutation)
- `after_state` (JSON / string, resulting state after mutation)
- `metadata` (JSON object, extra context such as reasons, criteria, scores)
- `idempotency_key` (string, deterministic deduplication key)
- `source_plan` (string, default `Plan_J`)
- `source_event_id` (string, nullable reference to J1 event)
- `occurred_at` (ISO8601 string)
- `created_at` (ISO8601 string)
- `is_immutable` (boolean, constant `true`)
