# Personnel Status View Evidence

### Visible Information
- Current Canonical Lifecycle Status (`Submitted`, `Under Review`, `Returned for Revision`, `Ready for Finalization`, `Completed`)
- Current Submitted Portfolio Version (e.g. `Version 1`, `Version 2`)
- Last Meaningful Workflow Action (e.g. `Portfolio Submitted`, `Revision Requested`, `Portfolio Resubmitted`, `Evaluation Finalized`)
- Revision Request details (overall message and item comments) when in `returned_for_revision` status
- Evaluation Result (`Passed` / `Retained`) once finalized
- Promotion Decision (`Approved` / `Not Approved`) if authorized by institutional policy

### Non-Visible / Redacted Information
- Internal evaluator notes/draft scores before completion
- HR-only promotion controls
- Other personnel members' evaluation data (strictly isolated by `personnel_profile_id`)
