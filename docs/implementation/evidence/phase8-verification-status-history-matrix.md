# Plan 05 Phase 8 — Verification Status & History Matrix
## Lifecycle States & Audit Trail Traceability

| Lifecycle Status | Meaning in Student View | Meaning in OSAD Review | Scoreable for Awards? | Permitted Actions |
|---|---|---|---|---|
| `draft` | Work in progress | Excluded from review queue | **NO** | Student Edit / Delete / Submit |
| `submitted` | Awaiting review | In coordinator review queue | **NO** | Coordinator Start Review |
| `under_review` | Being evaluated | Under active verification | **NO** | Coordinator Verify / Reject / Revisions |
| `revisions_requested`| Corrections required | Returned to student with remarks | **NO** | Student Edit & Resubmit |
| `verified` | Officially certified | Certified; eligible for award mapping | **YES** | OSAD Award Evaluation |
| `rejected` | Declined claim | Declined; audit trail preserved | **NO** | None (Immutable archive) |
