# Authoritative Event & Status Catalog (Phase J0 Freeze)

## 1. Canonical Lifecycle Statuses
1. `submitted`: Whole-portfolio package submitted for reviewer evaluation (Plan C).
2. `in_evaluation`: Active reviewer evaluation in progress (Plan G).
3. `returned_for_revision`: Whole-portfolio returned with deficiency feedback (Plan C3 / G).
4. `ready_for_finalization`: All criteria scored; ready for HR finalization (Plan H0).
5. `completed`: Finalized and locked with permanent decision (Plan H4).

## 2. Canonical Evaluation Results (Plan F)
- `Passed`: Meets score criteria.
- `Retained`: Score does not meet criteria.

## 3. Canonical Promotion Decisions (Plan H)
- `Approved`: HR / Board approved rank promotion.
- `Not Approved`: Retains current rank without promotion or demotion.
