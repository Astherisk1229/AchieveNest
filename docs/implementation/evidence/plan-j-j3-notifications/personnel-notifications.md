# Phase J3 Evidence: Personnel Notification Workflows

## Supported Notifications for Personnel
1. **Review Started**: Alerted when portfolio enters active review.
2. **Revision Requested**: Alerted when Dean/HR returns portfolio, including deficiency reason and prompt for requested evidence.
3. **Evaluation Finalized**: Neutral notification that evaluation cycle has finalized.
4. **Summary Available**: Notification that summary report PDF is ready.
