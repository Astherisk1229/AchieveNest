## 1. Document Purpose & Phase Objective

This document represents the authoritative deliverable for **SA-01.5: Required Metadata and Conditions**.

Building upon the frozen taxonomy mappings of **SA-01.1 through SA-01.4**, this phase defines the exact **structured metadata fields, evaluation operators, controlled vocabularies, and lifecycle/verification predicates** that a portfolio record must satisfy before it can be qualified for scoring.

### Non-Negotiable Architectural Principles
1. **Zero Invented Conditions:** Every metadata condition is derived exclusively from authoritative award specifications, published rubrics, database constraints, or the `PortfolioStructuredMetadataValidator` service.
2. **Taxonomy Match $\neq$ Qualification:** Category and sub-category alignment is a prerequisite, not a qualification. The record must satisfy all mandatory metadata conditions (`REQUIRED`).
3. **Deterministic Missing Metadata Behavior:** If a mandatory metadata field is missing or contains an invalid value, the engine marks the route `ROUTE_NOT_QUALIFIED` (`Reason: MISSING_REQUIRED_METADATA`). No default value is assumed.
4. **Preservation of Prior Frozen Baselines:** No award identifiers, criterion structures, caps, category boundaries, or sub-category allocations from SA-01.1–SA-01.4 have been altered.

## 3. Global Lifecycle and Verification Gates (Applied Across All Routes)

Before any route-level condition predicate is evaluated, every portfolio record must satisfy:

```text
1. Verification State:
   record.status == 'verified'  [OPERATOR: EQUALS]
   (Draft, submitted, rejected, or revision-requested records are strictly ineligible)

2. Lifecycle Validity:
   record.lifecycle_status == 'active'  [OPERATOR: EQUALS]
   (Archived, removed, or superseded records are strictly ineligible)

3. Date / Cycle Alignment:
   - Graduating Awards (Senior Scope): record.occurrence_date within Student Program Span
   - Non-Graduating / Annual Awards: record.academic_year == current_award_cycle.academic_year
```
