# Subject & Version Linkage Evidence

### Subject Linkage
- `subject_personnel_id`: Uniquely identifies the candidate whose evaluation dossier is affected.
- `evaluation_id`: References the evaluation cycle/dossier.
- `portfolio_version_id` & `portfolio_version_number`: Binds the action to the exact submission version (e.g. V1, V2, V3).
- `entity_type` & `entity_id`: References specific items when applicable (e.g. `evidence_item`, `score_entry`, `revision_request`).
