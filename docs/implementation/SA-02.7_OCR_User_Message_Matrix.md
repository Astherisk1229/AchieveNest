# SA-02.7 — OCR User Message & UI Indicator Matrix

## 1. Document Purpose
This document standardizes all user-facing notification banners, field-level microcopy, warning chips, and UI state indicators for OCR extraction and exception handling in AchieveNest.

---

## 2. Standardized User-Facing Message Matrix

| Exception / State Code | Message Type | User-Facing Microcopy / Notification | UI Placement | Action Button / Assist |
|---|---|---|---|---|
| **`EXTRACTED`** | `INFO` / `SUCCESS` | *"Document scanned successfully. Form fields have been pre-filled with suggestions. Please review all details before submitting."* | Top of modal / suggestion banner | "Review Details" |
| **`NO_VALUE`** | `NEUTRAL` | *"No specific value was detected for this field in the uploaded document. Please enter details manually."* | Field-level helper text | None (Focus input) |
| **`NO_MATCH`** | `WARNING` | *"The event or position described in the document could not be matched to a standard category option. Please select the most appropriate option from the list."* | Below dropdown selector | None (Dropdown active) |
| **`PARTIAL`** | `WARNING` | *"Some details (e.g. date or duration) were only partially detected. Please complete the missing information."* | Field-level warning badge | None (Focus input) |
| **`AMBIGUOUS` (Dates)** | `WARNING` | *"Multiple dates were detected in this document ({date_list}). Please verify or select the confirmed Date Achieved."* | Date field container | Quick-select date chips |
| **`AMBIGUOUS` (General)** | `WARNING` | *"Multiple possible values were detected. Please confirm the correct choice."* | Above ambiguous input | Value selection chips |
| **`INVALID_VALUE`** | `WARNING` | *"The extracted date or quantity was invalid and could not be pre-filled. Please enter the correct value manually."* | Field helper text | None |
| **`MANUAL_PRESERVED`** | `INFO` | *"Your manually entered value was preserved. Extracted suggestion: '{extracted_value}'."* | Field suggestion chip | "Use Extracted Value" |
| **`MANUALLY_OVERRIDDEN`**| `NEUTRAL` | *"Pre-filled suggestion was edited."* | Provenance metadata tooltip | "Reset to Suggested" |
| **`FAILED`** | `ERROR` / `WARNING` | *"OCR text extraction could not be completed for this file. Your uploaded document is safely attached. Please fill in the required details manually."* | Modal alert banner | "Dismiss" / "Enter Manually" |
| **`SERVICE_UNAVAILABLE`**| `WARNING` | *"Document scanner is temporarily busy or unavailable. Your evidence file has been uploaded safely. You may proceed with manual entry."* | Modal alert banner | "Continue Manually" |
| **`REPLACED_EVIDENCE`** | `INFO` | *"Evidence document replaced. New extraction suggestions are ready for your review."* | Evidence upload zone | "Apply New Suggestions" |

---

## 3. UI Indicator & Badge Guidelines

1. **Advisory Suggestion Chip**: Rendered in emerald/slate theme (`bg-emerald-50 text-emerald-700 border-emerald-200`) indicating: *"Suggested from document"*.
2. **Ambiguity Alert Chip**: Rendered in amber theme (`bg-amber-50 text-amber-700 border-amber-200`) with an `AlertTriangle` icon.
3. **Non-Blocking Error Banner**: Rendered in slate/amber theme with an informative tone to avoid causing panic; explicitly reminds the student that their document remains safely attached.
4. **Zero Verification Badges**: The modal and submission views must **never** render green "Verified" or "Approved" badges based on OCR results. Badges are strictly reserved for official OSAD reviewer approval actions.
