### 2. Remediation Strategy

- New submissions generated by the Phase 6 dynamic form will **never** write `rank_conferred` or overloaded `scope_level` strings.
- Instead, new records directly populate normalized structured keys (`placement`, `event_level`, `position_level`, `publication_status`, etc.) inside `structured_metadata` JSON.
- `AwardEvidenceMappingService` continues reading structured keys directly with zero text parsing for all newly submitted records.
