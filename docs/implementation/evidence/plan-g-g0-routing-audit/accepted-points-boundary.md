# Personnel Evaluation Track — Plan G — Phase G0: Accepted Points Ownership Boundary

## Boundary Specification: Claimed vs Deterministic vs Accepted Points

| Point Type | Definition & Origin | Controlled By | Authoritative Weight |
| :--- | :--- | :--- | :--- |
| **Claimed / Advisory Points** | Estimated values calculated during entry or OCR guidance (Plan A/C) | Personnel / Client UI | Zero authority (display/advisory only) |
| **Deterministic Raw / Capped Points** | Exact mathematical calculation from confirmed factor/matrix rules | Plan F Scoring Engine | Authoritative baseline for deterministic criteria |
| **Evaluator Accepted Points** | Official scores awarded after evaluator review/judgment | Authorized Evaluator (Plan G) within Plan F Ceilings | Authoritative value for judgment & verification items |

### Invariant Rules:
1. **Plan G Authority**: Plan G owns **where** accepted points are entered and **who** is authorized to enter them.
2. **Plan F Authority**: Plan F owns **whether the score is valid** (validating ceiling, negative values, and formula limits).
3. **Immutability of Baseline Rules**: Evaluators cannot override deterministic formulas (e.g. changing Ph.D. degree from 40 to 50).
