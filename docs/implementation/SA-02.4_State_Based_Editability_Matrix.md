## 1. Document Purpose

## 3. Verified Record Edit Policy (`RESUBMIT_TRIGGER`)

When a student edits any core metadata or evidence of a previously `verified` record:
1. The backend automatically resets the record status from `verified` to `submitted`;
2. A new `student_portfolio_verification_events` log is recorded (`event_type: 'resubmitted'`);
3. The previous verification snapshot is invalidated until re-reviewed by an authorized Evaluator or OSAD Moderator;
4. The record immediately leaves active award scoring pools until re-verified.
