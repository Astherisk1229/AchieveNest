## 1. Document Purpose & Phase Objective

This document defines the definitive **Required vs Optional Matrix** for every student-facing field across every finalized portfolio sub-category in AchieveNest.

### Non-Negotiable Invariants:
1. **Sub-Category Specificity:** Field requirements are defined per sub-category; no blanket generic rules.
2. **Scoring-Critical Metadata Safety:** Every metadata field required by SA-01.5 award routes is classified as `REQUIRED` or `CONDITIONALLY_REQUIRED`.
3. **Unrelated Field Suppression:** Unrelated fields are classified as `NOT_APPLICABLE` and must be hidden from the UI (never rendered disabled or optional).
4. **Draft vs Submit Distinction:** Draft saves allow incomplete fields; final submission (`submit_now = true`) enforces all `REQUIRED` and active `CONDITIONALLY_REQUIRED` fields.
