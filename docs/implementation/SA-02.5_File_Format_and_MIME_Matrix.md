## 1. Format Matrix Purpose

This matrix establishes the verified file extensions, MIME signatures, backend acceptance statuses, and OCR candidate eligibility for all student-uploaded documents.

---

---

## 3. Format Validation Rules

1. **Double Extension Guard:** Files with double extensions (e.g. `cert.php.pdf`) are sanitized and validated against actual binary MIME content.
2. **Empty File Guard:** Files with `0 bytes` are rejected with `EMPTY_FILE`.
3. **Size Ceiling:** Files larger than `10,485,760 bytes` are rejected with `FILE_TOO_LARGE`.
