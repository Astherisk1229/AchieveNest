# Final Database Table Summary

- `profiles`: Core identity profiles
- `personnel_profiles`: Personnel group, side, engagement, employment status, rank title
- `colleges`: Institutional Colleges
- `administrative_units`: Institutional Administrative Units / Departments
- `faculty_ranks`: 26 canonical Full-Time ranks
- `faculty_rank_transitions`: Allowed sequential transitions & PhD exception
- `part_time_faculty_titles`: 4 canonical Part-Time titles
- `personnel_portfolio_submissions`: Whole-portfolio submissions with multi-version support
- `personnel_accomplishments`: Accomplishment items reflected in portfolio
- `personnel_evaluations`: Evaluation cycle records, scales, scores, promotion decisions
- `personnel_evaluation_items`: Scored evaluation criteria items & evidence linkage
- `personnel_evidence_records`: Evidence file metadata, MIME type, storage keys
- `personnel_evaluation_audits`: Append-only audit trail entries
- `personnel_workflow_notifications`: Persisted event-driven user notifications
