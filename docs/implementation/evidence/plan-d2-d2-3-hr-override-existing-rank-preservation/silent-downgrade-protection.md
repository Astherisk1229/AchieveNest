# Phase D2-3: Silent Downgrade Protection

## Downgrade Prevention Rules
Plan E initial rank mappings resolve to entry-level ranks for qualifications (e.g. `Professor I` for PhD, `Instructor I` for BS). However, tenured and progressed faculty frequently hold higher ranks:

- **Saved Professor III**:
  - Qualification mapping resolves: `Professor I`
  - Current rank remains: `Professor III`
  - Silent downgrade is blocked.

- **Saved Senior Instructor IV**:
  - Qualification mapping resolves: `Instructor I`
  - Current rank remains: `Senior Instructor IV`
  - Silent downgrade is blocked.

- **Saved Professorial Lecturer (Part-Time)**:
  - Qualification mapping resolves: `Lecturer`
  - Current rank remains: `Professorial Lecturer`
  - Silent downgrade is blocked.
