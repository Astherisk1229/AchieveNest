# Plan H Phase H2 — Evaluation Result Display Evidence

### Display Rules
1. **Passed**:
   - Displays `Passed`.
   - Deliberation Notice: `Evaluation passed. Eligible to proceed to deliberation under Plan H.`
   - Evaluated current rank displayed unchanged.
   - Promotion decision displayed as `null` / `ready_for_deliberation`.
2. **Retained**:
   - Displays `Retained`.
   - Deliberation Notice: `Current rank/title retained. No rank adjustment required.`
   - Evaluated current rank displayed unchanged.
   - Promotion decision displayed as `null`.
