# Final Portfolio Versioning & Lifecycle Summary

- **Whole-Portfolio Submission**: Portfolios submitted as complete units.
- **Immutable V1**: Finalized/submitted versions are immutable.
- **Revision Request**: Reviewer provides mandatory overall revision message.
- **V2 Resubmission**: Successive version created while preserving V1 audit lineage.
- **Canonical Lifecycle**: `submitted` $\rightarrow$ `in_evaluation` $\rightarrow$ `returned_for_revision` $\rightarrow$ `ready_for_finalization` $\rightarrow$ `completed`.
