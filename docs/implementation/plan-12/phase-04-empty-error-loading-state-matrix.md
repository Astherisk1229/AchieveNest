# PLAN 12 — Phase 4 Empty/Error/Loading State Matrix
## AchieveNest — Student Profile & Institutional Relationship Visibility

---

# 1. State Presentation Strategy

| State Scenario | Visual Treatment | Message Displayed | Action Available |
|---|---|---|---|
| **Data Loading** | Centered Spinner & Skeleton | "Loading authoritative student profile..." | Non-blocking |
| **Fetch Error** | Rose alert card | "Unable to Load Profile" + details | "Retry" button |
| **Unassigned Organization** | Dashed muted container | "Student organization not yet assigned" | Informational |
| **Unassigned Coordinator** | Italic muted text inside Card | "Program coordinator not yet assigned" | Informational |
| **Unassigned Moderator** | Italic muted text inside Card | "Organization moderator not yet assigned"| Informational |
| **Missing Avatar** | Initials avatar fallback | e.g. "JD" with emerald styling | Default fallback |
