## 1. Audit Purpose

This audit tests backend vulnerability to mass-assignment attacks where malicious students craft API payloads attempting to inject protected or workflow-managed fields.

---

## 2. Mass-Assignment Vulnerability Test Matrix

| Crafted Payload Field Injected | Injected Value | Target Endpoint | Backend Processing Result | Security Outcome |
|---|---|---|---|---|
| `status` | `'verified'` | `POST /api/v1/portfolio` | Payload `status` key is ignored; set strictly to `'submitted'` or `'draft'`. | **PROTECTED** |
| `verified_by` | `'00000000-0000-0000-0000-000000000001'` | `POST /api/v1/portfolio` | Ignored by controller; not present in `student_portfolio_records` columns. | **PROTECTED** |
| `score` | `100.0` | `POST /api/v1/portfolio` | Blocked by `FORBIDDEN_METADATA_KEYS` in `PortfolioStructuredMetadataValidator` $\rightarrow$ `422 Unprocessable Entity`. | **BLOCKED** |
| `points` | `50.0` | `POST /api/v1/portfolio` | Blocked by `FORBIDDEN_METADATA_KEYS` $\rightarrow$ `422 Unprocessable Entity`. | **BLOCKED** |
| `award_id` | `'NOTRE_DAME_AWARD'` | `POST /api/v1/portfolio` | Blocked by `FORBIDDEN_METADATA_KEYS` $\rightarrow$ `422 Unprocessable Entity`. | **BLOCKED** |
| `student_profile_id`| `'victim-student-uuid'` | `POST /api/v1/portfolio` | Overwritten by `$actor['profile_id']` from verified JWT. | **PROTECTED** |
| `id` | `'custom-record-uuid'` | `POST /api/v1/portfolio` | Overwritten by `$this->genUuid()`. | **PROTECTED** |

---

## 3. Audit Verdict

All mass-assignment attack vectors are either actively blocked via validator rejection or rendered inert through server-side binding.
