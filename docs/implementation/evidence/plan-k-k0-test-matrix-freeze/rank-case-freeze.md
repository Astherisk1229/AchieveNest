# Rank Case Freeze — Plan K Phase K0

## Required Representative Rank Cases

1. **Full-Time Initial Recommendation Case**:
   - Qualification: `Master of Science` $\rightarrow$ Suggests `Assistant Professor I` via Plan E resolver.
2. **Part-Time Initial Recommendation Case**:
   - Qualification: `Doctor of Philosophy (PhD)` $\rightarrow$ Suggests `Professorial Lecturer` via Part-Time resolver.
3. **Board-Passer / Professional Path**:
   - Verified Licensure $\rightarrow$ Resolves to `Senior Instructor` (Licensure tier).
4. **Sequential Rank Progression Case**:
   - Starting Rank: `Instructor I` $\rightarrow$ Passed Evaluation + Approved Promotion $\rightarrow$ Promotes to `Instructor II`.
5. **Verified PhD Jump Case**:
   - Starting Rank: `Assistant Professor I` $\rightarrow$ Verified PhD + Passed Evaluation + Approved Promotion $\rightarrow$ Promotes directly to `Professor I` (Plan E PhD exception).
6. **Existing Higher-Rank Preservation Case**:
   - Saved Rank: `Professor III` $\rightarrow$ Recommendation suggests `Professor I` $\rightarrow$ Official saved rank remains `Professor III` (no silent downgrade).
7. **No Auto-Promotion D2 Modal Case**:
   - Modal recommendation remains advisory and cannot alter existing rank without explicit HR selection.
8. **Non-Teaching Faculty + Non-Academic Case**:
   - Formally designated as `NO GUESSED ACADEMIC-RANK RULE`; governed by institutional non-academic compensation scales.
