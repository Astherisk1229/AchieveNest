# PLAN 12 — Phase 1 Personnel Visibility & Privacy Matrix
## AchieveNest — Student Profile & Institutional Relationship Visibility

---

# 1. Personnel Data Classification & Privacy Boundary

| Personnel Profile Field | Student-Visible? | Classification | Rationale |
|---|---|---|---|
| **Full Name / Title** | **YES** | Public Institutional Contact | Institutional advisory role |
| **Role Designation (e.g. Program Coordinator)** | **YES** | Public Institutional Contact | Clear role identification |
| **Institutional Email (`@ndmu.edu.ph`)** | **YES** | Public Institutional Contact | Official communication channel |
| **Profile Avatar URL** | **YES** | Public Institutional Contact | Visual identification |
| **Personal Mobile / Phone** | **NO** | Private / Protected | Privacy compliance |
| **Personal Email** | **NO** | Private / Protected | Privacy compliance |
| **Home Address** | **NO** | Private / Protected | Privacy compliance |
| **Password Hash / Auth Credentials** | **NO** | Security Sensitive | Zero credential exposure |
| **Evaluation / Scoring / HR Dossier** | **NO** | HR Sensitive | Strict internal governance |
