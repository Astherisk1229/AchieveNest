# Plan F Result Integration Verification

## Consumption of Plan F Authoritative Results

1. **No Duplicated Result Rules**:
   - Plan G consumes Passing Thresholds (Admin 120 / Non-Teaching 75) and results from Plan F.
2. **Canonical Outcomes**:
   - Only `Passed` or `Retained` can be determined.
3. **Passed != Promoted Invariant**:
   - A `Passed` result does NOT modify academic rank or approve promotion. Promotion approval is the sole authority of Plan H.
