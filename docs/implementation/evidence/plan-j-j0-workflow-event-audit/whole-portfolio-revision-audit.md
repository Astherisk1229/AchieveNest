# Whole-Portfolio Revision Semantics Audit

## Principle
- The Personnel evaluation track operates on **whole-portfolio** submission packages.
- A revision request unlocks the author's working portfolio draft for modifications while leaving submitted snapshot Version N locked and immutable.
- Individual item deficiency remarks are supplemental annotations to guide the author, but the return and resubmission transitions apply strictly to the whole portfolio.
- Resubmitting produces Version N+1 under the same evaluation root.
