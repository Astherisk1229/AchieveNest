# Reviewer Historical Evidence Validation

## Immutable Point-in-Time Review
- Reviewer workspace renders submitted evidence from `personnel_evaluation_items.evidence_id`.
- If an author replaces evidence in later working revisions (e.g. Evidence B replaces Evidence A), reviewing Version 1 continues to preview Evidence A.
- Reviewing Version 2 previews Evidence B.
- Live replacement evidence is never substituted into submitted historical snapshots.
