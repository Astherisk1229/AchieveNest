## 3. Data Integrity Guarantee

Unrecognized strings that do not map to any canonical vocabulary or valid alias are strictly rejected by `PortfolioStructuredMetadataValidator` with an `INVALID_CONTROLLED_VALUE` error, preventing corrupted data from entering the database.
