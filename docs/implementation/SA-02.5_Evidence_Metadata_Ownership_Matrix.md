## 1. Matrix Purpose

This matrix separates student-driven evidence actions from system-managed file attributes and cryptographic integrity metadata.

---

## 2. Evidence Property Ownership Table

| Evidence Property | Database Column | Ownership State | Student Editable? | Managing Service / Generating Process | Security Guarantee |
|---|---|---|---|---|---|
| **File Buffer Selection** | Client Payload | `STUDENT_EDITABLE` | `YES` | Student File Picker / Drag-and-Drop | Allowed only in draft/submitted states |
| **Original Filename** | `original_filename` | `SYSTEM_CAPTURED` | `NO` | `UploadedFile::getClientName()` | Sanitized against null-byte injection |
| **Storage Path** | `storage_path` | `INTERNAL_ONLY` | `NO` | `LocalEvidenceStorageService` | Stored in isolated non-web-accessible directory |
| **MIME Type** | `mime_type` | `SYSTEM_DERIVED` | `NO` | `finfo_file` (Binary Inspection) | Client-supplied Content-Type header ignored |
| **File Size** | `file_size_bytes` | `SYSTEM_DERIVED` | `NO` | `filesize($tempPath)` | Enforced $\le 10485760$ bytes |
| **SHA-256 Hash** | `sha256_hash` | `SYSTEM_DERIVED` | `NO` | `hash_file('sha256', $tempPath)` | Cryptographic tamper-proofing |
| **Evidence ID** | `id` | `INTERNAL_ONLY` | `NO` | Server `genUuid()` | Auto-generated UUID v4 |
| **Record Link** | `portfolio_record_id` | `INTERNAL_ONLY` | `NO` | Foreign Key Binding | Session-bound to authenticated student record |
| **Upload Timestamp** | `created_at` | `SYSTEM_MANAGED` | `NO` | Database Timestamp (`NOW()`) | Immutable audit trail |

---

## 3. Verdict

Students control only the selection of their evidence document. All storage paths, cryptographic hashes, MIME types, and database linkages remain strictly system-controlled.
