## 3. Two Core Invariants Proven End-to-End

### Invariant 1: Incomplete Submission Prevention
$$\text{Mandatory Base / Sub-Category Field Missing} \implies \text{Submission Blocked}$$
No student can submit an achievement record lacking required base fields, sub-category details, or evidence attachments.

### Invariant 2: OCR Non-Verification
$$\text{OCR Extraction Output} = \text{Pre-Fill Suggestion} \ne \text{Verified Record}$$
$$\text{Status} = \text{pending\_verification} \implies \text{Award Points} = 0.00$$
High OCR confidence or automated parsing never marks a submission as verified. Award points remain at zero until official OSAD reviewer evaluation and verification.
