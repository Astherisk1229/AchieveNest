# Legacy Reconciliation UI Presentation — Plan D2 Phase D2-4

## Detection & Visual Indicators
For existing personnel holding unmatched legacy ranks/titles not in the authoritative Plan E catalog (e.g., `Senior Lecturer III (Legacy)`):
1. **Pill Badge**: Displays a violet `Legacy Record` badge.
2. **Reconciliation Notice Banner**:
   `Legacy Unmatched Rank Detected: Saved legacy rank is not in the current catalog. It will remain preserved unless HR deliberately selects a valid current catalog rank.`
3. **No Forcible Invalidation**: Legacy rank remains preserved unless deliberately updated by HR.
