# Return-for-Revision Journey Evidence

### Whole-Portfolio Revision Workflow
1. Evaluator issues return-for-revision with mandatory overall message and deficiency reason.
2. Optional item/criterion comments remain strictly subordinate to the whole-portfolio request.
3. Status becomes `returned_for_revision`.
4. Prior submitted version (e.g. V1) remains immutable and frozen.
5. Candidate receives single actionable notification linking to `/personnel/portfolio/revision`.
