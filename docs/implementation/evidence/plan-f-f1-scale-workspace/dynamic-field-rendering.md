# Plan F Phase F1 Evidence: Dynamic Field & Value Rendering

## Dynamic Fields per Selected Criterion

1. **Degree/s (A.1)**: `degree_type` (dropdown: Ph.D., Ph.D. Units, MA, MA Units), `degree_name_or_units` (text/number), `institution` (text).
2. **Professional Memberships (A.2)**: `organization_name`, `membership_role` (Member, Officer), `period`.
3. **Seminars/Trainings (A.3)**: `seminar_title`, `scope` (International, National, Regional, City/Provincial, In-House), `venue`, `date`.
4. **Guest Lecturer (B.1)**: `activity_title`, `sponsoring_organization` (NDMU, External), `extent_of_talk` (1 hr, Half day, 1 day, 2 days, >2 days), `participant_reach` (Local, Regional, National, International), `role` (Speaker, Reactor, etc.), `date`.
5. **Publication (B.2)**: `publication_title`, `location_scope`, `publication_type` (Book, Article, etc.), `date`.
6. **Instructional Materials (B.5)**: `material_title`, `material_type` (Audio-Visual, Modules, Bound Workbook, etc.), `date`.
