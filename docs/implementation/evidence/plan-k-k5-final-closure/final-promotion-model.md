# Final Promotion Decision Model Summary

- **HR Promotion Decision**: `Approved` or `Not Approved`.
- **Approved Decision**: Updates rank to exactly next sequential step (`ASSISTANT_PROFESSOR_I` $\rightarrow$ `ASSISTANT_PROFESSOR_II`) or authorized PhD exception (`ASSISTANT_PROFESSOR_I` $\rightarrow$ `PROFESSOR_I`).
- **Not Approved Decision**: Official rank remains unchanged.
- **Retained Result**: Retains rank without promotion.
- **Part-Time Faculty**: Strictly excluded from rank progression.
