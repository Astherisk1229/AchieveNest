# Dean Status View Evidence

### Visible Information
- Canonical Lifecycle Status (`Submitted`, `Under Review`, `Returned for Revision`, `Ready for Finalization`, `Completed`)
- Current Submitted Portfolio Version (`Version 1`, `Version 2`, etc.)
- Reviewer Assignment state (`Dean`)
- Last Meaningful Workflow Event with timestamp
- Active Revision State (`open` vs `resolved` requests)
- Scoring & Finalization Readiness indicators

### Non-Visible / Redacted Information
- HR-only promotion decision entry controls
- Cross-college evaluation dossiers (strictly constrained to Dean's assigned college)
