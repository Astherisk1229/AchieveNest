## Matrix
| Concern | Owning Track / Plan | Phase / Service | Status |
|---|---|---|---|
| Submission / Versioning / Portfolio Snapshot | Plan C | Submissions | Stable / Complete |
| Personnel Classification & Status Master Data | Plan D | Classification / Master Data | Stable / Complete |
| Rank Catalog & Progression Rules | Plan E | `FacultyRankEngineService` | Stable / Complete |

| Evidence Lifecycle & Storage Management | Plan I | Evidence System | Independent Track |
| Notifications & Systemwide Audit UX | Plan J | Notification Engine | Independent Track |

## Plan H Boundaries
Plan H strictly consumes outputs from Plans C, D, E, F, and G without encroaching on their internal rules or absorbing responsibilities designated for Plans I and J.
