### Prohibition of Unauthorized Outcome Labels:
Plan F explicitly prohibits generating any of the following labels:
- `Failed`, `Promoted`, `Approved`, `For Promotion`, `Qualified`, `Disqualified`, `Deferred`, `Rejected`.
